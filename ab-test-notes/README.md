# A/B Testing — конспект курса (Глеб Михайлов)

Пять ноутбуков, сквозная линия: метрики классификатора → случайность и
Монте-Карло → планирование эксперимента → проверка гипотез → p-value.


## Ноутбуки

1. [Метрики классификатора (тест на COVID)](./1_ab_test_covid.ipynb)
   TPR/TNR, FPR/FNR, Accuracy. Почему Accuracy мало: считаем ошибки
   на группах отдельно.

2. [Выбор теста по бизнес-приоритету (тест на беременность)](./2_ab_test_pregnancy.ipynb)
   Sensitivity важнее specificity, когда пропуск дороже ложной тревоги.

3. [Случайность, Монте-Карло, планирование теста](./3_ab_test_metrics.ipynb)
   Закон больших чисел, симуляции A/B, калькулятор теста
   (MDE, Power, Significance), `proportions_ztest`.

4. [Проверка гипотез: монетка и удовлетворённость](./4_ab_test_hypotheses.ipynb)
   FPR и TPR через симуляции, trade-off alpha–beta, размер выборки под MDE.

5. [p-value](./5_ab_test_p_value.ipynb)
   p-value как доля исходов «не менее экстремальных» при H0; сверка
   симуляции с z-тестом.

## Траектория

метрики → случайность → Монте-Карло → планирование → гипотезы → p-value
