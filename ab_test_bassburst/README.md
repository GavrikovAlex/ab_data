## ab_test_bassburst

Практический проект по A/B-тестированию на датасете BassBurst (лендинг интернет-магазина аудиотехники).

**Цель:** проанализировать влияние трёх вариантов дизайна лендинга (Vibrant, Cold, Heat) на конверсию и другие поведенческие метрики с применением статистических методов.

**Что внутри:**
- загрузка и предобработка данных;
- разведочный анализ (EDA);
- дизайн эксперимента и расчёт размера выборки;
- проверка статистических гипотез (конверсия, время на сайте, выручка);
- выводы и продуктовые рекомендации.

**Датасет:** [BassBurst на Kaggle](https://www.kaggle.com/datasets/sandeep1080/bassburst/data)
