## A/B-тестирование: оптимизация конверсии лендинга
Практический проект по A/B-тестированию на датасете BassBurst — 30 000 сессий посетителей лендинга интернет-магазина аудиотехники.

**Цель:**

Проанализировать влияние трёх вариантов дизайна лендинга (Vibrant, Cold, Heat) на конверсию и вспомогательные поведенческие метрики с применением статистических методов.

**Что внутри:**
- Загрузка и предобработка данных — приведение колонок к snake_case, замена текстовых заглушек на NaN, проверка дубликатов и аномалий.

- Дизайн эксперимента — выбор основной и вспомогательных метрик, расчёт размера выборки под MDE +10%, оценка детектируемого MDE при текущем объёме данных.

- Разведочный анализ (EDA) — распределения метрик по группам, конверсия, проверка баланса групп (SRM), проверка нормальности.

- Проверка гипотез — хи-квадрат + попарные сравнения для конверсии, ANOVA + Tukey HSD для времени на сайте, bootstrap для выручки.

- Выводы и рекомендации — продуктовое решение по выбору дизайна и ограничения исследования.

**Инструменты:**
Python (pandas, numpy, scipy, statsmodels, seaborn, matplotlib, sklearn).

**Ключевой результат:**
Дизайн Cold показал значимо лучшую конверсию — 18.08% против 15.17% (Heat) и 12.13% (Vibrant). Разница Cold vs Vibrant — 5.95 п.п. (+49% относительных), p < 0.001. Вспомогательные метрики (time_spent, revenue) значимо не различаются.

**Рекомендация:**
Внедрить дизайн Cold как основной.

**Датасет:** [BassBurst на Kaggle](https://www.kaggle.com/datasets/sandeep1080/bassburst/data)
